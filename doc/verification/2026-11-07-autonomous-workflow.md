# 通用流程端到端验证

2026-11-07 的隔离实例使用独立数据库、合成董事会身份与预设静态 Web 场景。TWF-1 至 TWF-13 全部完成。产品固定提交为 `b5e7adb515764b68d78be4b09ef22c44a9b3ab99`。

CEO 收齐四岗咨询后创建真实问答卡。测试董事会通过正常接口答复，随后团队完成启动确认、规格冻结、仓库创建与绑定、实现、RE 交接、独立 QA、PM 体验签核和 CEO 交付。PM 检查了四个模拟视口。实机、真实输入法和 200% 缩放未覆盖。

受控浏览器故障自动生成唯一 CTO 修复任务。CTO 首次操作因工作区权限不足被拒，CEO 将修复任务绑定到已有授权工作区，CTO 恢复浏览器后，原 QA 自动接续，PM 随后签核。

本轮修复让开工预检可以在项目尚未绑定时使用当前任务的已授权工作区，并补充复用现有授权工作区的恢复指引。相关回归 66 项通过。首轮测试实例经历代理配置缺失，测试回答器也曾把文本题误当选择题。两项测试配置问题纠正后完成验证。试点覆盖本地静态 Web 交付。
